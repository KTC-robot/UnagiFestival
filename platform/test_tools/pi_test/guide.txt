IM920＋PS5 十字キー PI制御調整テスト

【目的】
十字キーで毎回同じ目標rpmを出し、M3508/C620の速度PI制御の
Kp・Kiを新しい機体重量と重心に合わせて調整します。

【使用する構成】
PS5 → Raspberry Pi → IM920 → ESP32 → TJA1051 → C620×4 → M3508×4

Raspberry Pi側のconfig.py、handler.py、main.pyは変更不要です。
サーボ命令はESP32側で無視し、PCA9685のCH0～CH15は起動時にFULL OFFにします。

【置き換え先】
~/UnagiFestival/platform/esp32_rx/main.cpp

通常運転用main.cppを必ずバックアップしてから置き換えてください。

============================================================
コントローラー操作
============================================================

十字キー上       前進（一定rpm）
十字キー下       後退（一定rpm）
十字キー右       右平行移動（一定rpm）
十字キー左       左平行移動（一定rpm）
十字キーを離す   停止

L1               テストrpmを200下げる
R1               テストrpmを200上げる

L2               Kpを0.10下げる
R2               Kpを0.10上げる

SQUARE           Kiを0.02下げる
TRIANGLE         Kiを0.02上げる

L3               電流指令上限を500下げる
R3               電流指令上限を500上げる

CIRCLE           積分値をリセット
OPTIONS          現在のKp・Ki・rpm・電流上限を送信
TOUCHPAD         Kp=0.50、Ki=0.00へ戻す

CROSS            通常停止
PS               非常停止（ラッチ）
SHARE            非常停止解除

スティック入力では足回りは動きません。

============================================================
初期値
============================================================

Kp = 0.50
Ki = 0.00
テストrpm = 1200
電流指令上限 = 3000

テレメトリ例:
PFL T1200 R1170 C680

PFL = 左前輪
T   = PIへ入っている目標rpm
R   = 実測rpm
C   = C620へ送った電流指令

設定例:
CFG K500 I0 R1200 C3000

KとIは1000倍表示です。
K500 = Kp 0.500
I200 = Ki 0.200

============================================================
PI調整手順
============================================================

1. 最初は車輪を床から浮かせる
2. C620 IDと回転方向を確認する
3. Ki=0の状態でKpを調整する
4. Kp決定後にKiを調整する
5. 最終重量・最終姿勢で床上試験する

Kp調整:
・目標rpmへの到達が遅い → Kpを上げる
・rpmが行き過ぎる、振動する、電流が激しく反転する → Kpを下げる
・振動し始める直前のKpから約20%下げた値を候補にする

Ki調整:
・負荷をかけると目標rpmとの差が残る → Kiを上げる
・rpmがゆっくり周期的に上下する → Kiを下げる

最初は1200rpm程度、短い時間で確認してください。
PSボタンと主電源をすぐ操作できる状態で行ってください。

============================================================
起動
============================================================

ESP32へ書き込み:
cd ~/UnagiFestival
sudo /home/ktc/.platformio/penv/bin/pio run \
  -e esp32_rx \
  -t upload \
  --upload-port /dev/ttyUSB0

Raspberry Pi:
cd /home/pi/test_tool
export PYTHONPATH=$PWD/src
python3 -m unagifestival.tools.ps_controller.main

床上走行時はUSBケーブルを外し、IM920＋PS5で操作します。

【重要】
コントローラーで変更したKp・KiはESP32を再起動すると初期値に戻ります。
決定値を通常運転用main.cppのSPEED_KP・SPEED_KIへ反映してください。
