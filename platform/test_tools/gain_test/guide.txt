IM920＋PS5 十字キー 車輪ゲイン調整テスト

【目的】
PI制御のKp・Kiを決定した後、床上で前進・後退・右移動・左移動を行い、
WHEEL_GAIN_FWD / BWD / RIGHT / LEFTを決定します。

【使用する構成】
PS5 → Raspberry Pi → IM920 → ESP32 → TJA1051 → C620×4 → M3508×4

Raspberry Pi側のconfig.py、handler.py、main.pyは変更不要です。
サーボ命令はESP32側で無視し、PCA9685のCH0～CH15は起動時にFULL OFFにします。

【置き換え先】
~/UnagiFestival/platform/esp32_rx/main.cpp

============================================================
最初にKp・Kiを反映
============================================================

main.cpp上部の次の2行を、PI調整で決定した値へ変更します。

static const float FIXED_SPEED_KP = 1.00f;
static const float FIXED_SPEED_KI = 0.20f;

4方向のゲインはすべて1.000から開始します。

============================================================
コントローラー操作
============================================================

十字キー上       FWDゲインを使用して前進
十字キー下       BWDゲインを使用して後退
十字キー右       RIGHTゲインを使用して右平行移動
十字キー左       LEFTゲインを使用して左平行移動
十字キーを離す   停止

最後に押した方向のゲイン配列が、調整対象として残ります。

L1               テストrpmを200下げる
R1               テストrpmを200上げる

L2               選択する車輪を1つ戻す
R2               選択する車輪を1つ進める

車輪の順番:
FL → FR → RL → RR

SQUARE           選択ゲインを0.005下げる
TRIANGLE         選択ゲインを0.005上げる

CIRCLE           現在選択中のゲインを送信
OPTIONS          4方向すべてのゲイン配列を順番に送信
TOUCHPAD         選択中の1項目だけ1.000へ戻す

CROSS            通常停止
PS               非常停止（ラッチ）
SHARE            非常停止解除

スティック入力では足回りは動きません。

============================================================
表示の読み方
============================================================

選択値:
G F FL=1005

F  = FWD配列
FL = 左前輪
1005 = 1.005

OPTIONSを押したとき:
GF 1000 1005 995 1000
GB 1000 1000 1000 1000
GR 1000 1000 1000 1000
GL 1000 1000 1000 1000

順番は必ず:
FL, FR, RL, RR

数値は1000分の1です。
995  = 0.995
1000 = 1.000
1005 = 1.005

============================================================
調整手順
============================================================

1. PI調整済みのKp・Kiをコードへ入力
2. 機体を最終重量・標準姿勢にする
3. 全ゲイン1.000で走らせる
4. 前進、後退、右移動、左移動を別々に調整
5. 1回に0.005ずつ変更
6. 同じ条件で最低3回走らせる
7. OPTIONSで最終値を表示して記録する

前進中に右へ曲がる場合の例:
・左側が強すぎる可能性 → FL/RLを少し下げる
・右側が弱い可能性 → FR/RRを少し上げる

前進中に左へ曲がる場合は逆方向に調整します。

横移動はメカナムローラーと荷重の影響が大きいため、
RIGHTとLEFTを必ず別々に調整してください。

毎回そろえる条件:
・バッテリー残量
・機体重量
・アームの姿勢
・床材
・走行距離または走行時間
・テストrpm

走るたびにずれる方向が異なる場合は、ゲインではなく、
タイヤの滑り、ローラー、機械的ガタ、配線、重心変化を確認してください。

============================================================
起動
============================================================

ESP32へ書き込み:
cd ~/UnagiFestival
sudo /home/ktc/.platformio/penv/bin/pio run \
  -e esp32_rx \
  -t upload \
  --upload-port /dev/ttyUSB0

Raspberry Pi:
cd /home/pi/test_tool
export PYTHONPATH=$PWD/src
python3 -m unagifestival.tools.ps_controller.main

床上走行時はUSBケーブルを外し、IM920＋PS5で操作します。

【重要】
コントローラーで変更したゲインはESP32を再起動すると1.000へ戻ります。
OPTIONSで表示した最終値を通常運転用main.cppの
WHEEL_GAIN_FWD / BWD / RIGHT / LEFTへコピーしてください。
